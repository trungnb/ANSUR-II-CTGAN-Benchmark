# Dataset used by the notebooks

The source code reads these existing CSV URLs:

- [ANSUR II FEMALE Public.csv](https://raw.githubusercontent.com/senihberkay/US-Army-ANSUR-II/master/ANSUR%20II%20FEMALE%20Public.csv)
- [ANSUR II MALE Public.csv](https://raw.githubusercontent.com/senihberkay/US-Army-ANSUR-II/master/ANSUR%20II%20MALE%20Public.csv)

These links are the mirror used in the notebooks, not a new dataset release or an
assertion that the mirror is the original publisher. The code references the mutable
`master` branch; the exact historical input revision is unknown. Redistribution terms
have not been established in this portfolio. Source CSVs and synthetic row-level tables
are not bundled. Check upstream terms before downloading or reusing data.

The combined table has 6,068 records in saved notebook outputs. Columns cover
anthropometric measurements and demographics. The experiment targets are Gender,
Age_Group and DODRace; no disease outcome is modeled. Individual row previews were
removed from the public notebooks. Only aggregate evaluation outputs are retained.
