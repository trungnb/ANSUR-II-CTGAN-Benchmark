# Project instructions

This repository presents historical exploratory notebooks and saved results.
Preserve analysis cell sources, parameters, and their order. Do not execute
segmentation, model training, or a reproduction audit without an explicit request.
The repository owner requested presentation and publication, with no analysis rerun.

Raw data are immutable and excluded from Git. Never commit raw images, participant
records, credentials, or `.local-originals/`. Preserve the local originals.
Every published result and figure must have a source in `docs/data-provenance.md`.
Never describe saved outputs as newly reproduced or clinically validated.
The locked Python environment supports chart rendering and optional notebook viewing;
it is not the historical analysis environment.

Follow `docs/governance/` before substantial changes. LOCKED decisions require
explicit user approval to change.
