# Release scope and roadmap

The historical release packages existing notebooks, saved results and figures for GitHub.

A separate benchmark v2 is now approved and implemented as code. Its next research steps are:

1. install the pinned v2 environment and execute the complete multi-seed benchmark;
2. inspect convergence, failures, class coverage and generated-data validity;
3. aggregate seed-level quality and utility with uncertainty summaries;
4. add formal privacy-risk metrics before making privacy-related claims;
5. update the README only after v2 results have been independently checked.

Historical notebook outputs are immutable provenance and must not be overwritten by v2.
